## Como usar este catálogo

- Abra o link do projeto para consultar README, arquivos, licença, instalação e dependências.
- Para ter uma cópia integral no seu GitHub, use **Fork** no próprio GitHub quando permitido pela configuração do projeto.
- Antes de reutilizar ou instalar, confira a licença, segredos, dependências, scripts de instalação e requisitos de infraestrutura.
- Repositórios arquivados podem estar desatualizados; não os trate como prontos para produção.

## Limite desta cópia

Este catálogo não é um espelho dos repositórios. O código-fonte, histórico de commits, issues e releases continuam nos repositórios originais. A integração disponível nesta conversa permite registrar arquivos no seu repositório, mas não oferece uma ação de fork em lote.
